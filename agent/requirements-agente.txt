# Para empaquetar como .exe (no es dependencia de runtime). En Red A no hay
# Python, asi que el agente SIEMPRE va empaquetado:
#   pip install pyinstaller

#
# --copy-metadata NO es opcional: t61codec (dependencia de puresnmp) pide su
# propia metadata al importarse. Sin esos flags el .exe compila sin quejarse
# y revienta al arrancar con:
#     PackageNotFoundError: No package metadata was found for t61codec
#
# Compilar desde un venv limpio con SOLO estas dependencias: si se usa el
# Python global, PyInstaller arrastra todo el site-packages (el .exe pasa de
# 32 MB a 106 MB).
#
# api_url.py debe estar en la misma carpeta al compilar -- PyInstaller lo
# incluye solo por seguir el import, no hay que listarlo aparte.
